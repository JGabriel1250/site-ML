# ⚖️ Maria Luiza Lisboa | Advocacia

Site institucional desenvolvido para a advogada **Maria Luiza Lisboa (OAB/SE 16.773)**, com foco em transmitir credibilidade, profissionalismo e proximidade com seus clientes.

O projeto foi desenvolvido utilizando **HTML5, CSS3 e JavaScript puro**, priorizando performance, organização de código, responsividade e facilidade de manutenção.

🔗 **Site Online:** https://marialuiza-adv.vercel.app/

## 📂 Estrutura do Projeto

```text
site-ML/
│
├── index.html
├── script.js
│
├── css/
│   ├── main.css
│   ├── variables.css
│   ├── reset.css
│   ├── typography.css
│   ├── layout.css
│   ├── header.css
│   ├── hero.css
│   ├── sections.css
│   ├── footer.css
│   ├── utilities.css
│   └── responsive.css
│
└── assets/
```

### Organização dos Arquivos CSS

| Arquivo | Responsabilidade |
|----------|----------------|
| main.css | Importação central dos estilos |
| variables.css | Variáveis globais, cores e fontes |
| reset.css | Reset e estilos base |
| typography.css | Tipografia e textos |
| layout.css | Containers e estrutura geral |
| header.css | Cabeçalho e navegação |
| hero.css | Seção principal |
| sections.css | Cards e seções do site |
| footer.css | Rodapé |
| utilities.css | Utilitários e animações |
| responsive.css | Responsividade |

## 🚀 Como Executar Localmente

Clone o repositório:

```bash
git clone https://github.com/JGabriel1250/site-ML.git
```

Entre na pasta:

```bash
cd site-ML
```

Abra o arquivo `index.html` diretamente no navegador.

Ou utilize um servidor local:

```bash
python -m http.server 8000
```

Acesse:

```text
http://localhost:8000
```
